### Detailed description

The dashboard field is plain text, so paste this block as is:

```
Export Confluence pages to PDF in seconds: one page, a whole page tree, a folder, or a page together with everything it links to, as one clean, searchable PDF.

Confluence's built-in PDF export runs on the server and handles one page at a time. Fast PDF Export for Confluence builds the PDF in your browser instead, using the session you are already logged in with.

EXPORT MODES
• This page: one click, or press Alt+Shift+P
• This page + children: the whole subtree in sidebar order, with an optional depth limit
• This folder: everything in a folder, recursively
• Pages linked from this page: follow links 1 or 2 hops deep, with no duplicates
• Choose pages from tree: tick exactly the pages you want
• Entire space: every page of the space, in sidebar order

A PDF YOU CAN ACTUALLY USE
• Vector PDF: selectable and searchable text, sharp images, clickable links
• Cover page with title, source, date, author and page count
• Clickable table of contents and PDF bookmarks that follow the page tree
• Every page starts on a new sheet, with its breadcrumb, last-updated date and a link to the original
• Links between exported pages jump inside the PDF
• Page numbers, paper size (A4, Letter, Legal, A3), orientation and margins
• Optional: one PDF per page, bundled in a ZIP
• Optional: custom CSS for your own branding

HANDLES REAL-WORLD PAGES
• Tables, code blocks, panels, layouts, status lozenges, Jira issue tables and images
• Expand macros are printed open
• Content that can't be printed (embeds, iframes, whiteboards, databases) gets a visible placeholder with a link. Nothing disappears silently.
• Optional Live render: diagrams and charts drawn by apps such as draw.io or Gliffy are printed from the real page and merged in the right place
• Pages you can't view are skipped and listed. The rest of the export continues.
• Rate limits from Confluence are handled automatically

PREVIEW BEFORE YOU EXPORT
See every page that will be included, untick the ones you don't need, and follow the progress with a cancel button and an error summary.

WORKS WITH YOUR CONFLUENCE
• Confluence Cloud (*.atlassian.net and custom domains)
• Confluence Data Center / Server 7.x and newer
• Google Chrome, Microsoft Edge and other Chromium browsers

PRIVATE BY DESIGN
• Everything happens on your device. No servers, no accounts, no API tokens.
• Read-only: the extension only reads from Confluence and never changes anything.
• No analytics, no tracking. Images embedded in your pages load from wherever they are hosted, just like when you view the page.
• No access to any site until you allow it, one Confluence site at a time.
• You can only export what you are already allowed to see.

GOOD TO KNOW
• While a PDF is being printed, Chrome briefly shows a bar saying the extension "started debugging this browser". This is how Chrome shows that its built-in PDF printer is in use, and the bar disappears as soon as printing finishes.
• Diagrams from Confluence apps need Live render, which is slower.

FOR IT ADMINS
Supports force-installation and managed policy: blocked space keys, a maximum page count, default export options and turning off live render.

"Confluence" is a trademark of Atlassian. This extension is not affiliated with or endorsed by Atlassian.
```

## Privacy practices tab

### Single purpose

```
Export Confluence pages that the user is viewing (a single page, a page tree, a folder, linked pages or a manual selection) into a PDF file, generated locally in the browser.
```

### Permission justifications

**activeTab**
```
When the user clicks the toolbar button, presses the keyboard shortcut or uses the context menu, the extension reads the current tab's URL and the Confluence page identifiers in it (page, folder or space, plus the site's base URL), so it knows what to export. It has no access to the tab without one of these user actions.
```

**scripting**
```
Used to run the extension's own bundled scripts (no remote code) in Confluence tabs on sites the user has allowed: (1) to detect the Confluence page in the active tab, (2) in a background tab the extension opens on the same Confluence site, to read page content through Confluence's REST API with the user's existing session and assemble a print-ready document, and (3) for the optional Live render mode, to expand macros and hide the app's navigation before printing a page.
```

**debugger**
```
Used only to call the Chrome DevTools Protocol method Page.printToPDF on a tab that the extension opened itself (the export tab or a live-render tab). This is the only way for an extension to produce a vector PDF with selectable text, working links and bookmarks without showing a print dialog for every export. The extension attaches right before printing, reads the PDF stream and detaches immediately (always, including on errors and cancel). It never attaches to the user's other tabs and does not inspect, modify or record any other debugging data. If the debugger is unavailable, the extension falls back to the browser's standard print dialog.
```

**storage**
```
chrome.storage.sync stores the user's preferences (default paper size, margins, toggles, concurrency). chrome.storage.local stores the optional custom print CSS. chrome.storage.session holds the state of a running export (page list and progress) so the export survives the service worker being suspended. It is cleared when the browser closes. chrome.storage.managed reads optional policy set by an organization's administrator (for example, blocked spaces or a maximum page count).
```

**downloads**
```
Saves the generated PDF (or the ZIP of separate PDFs) to the user's downloads folder through chrome.downloads, which respects the user's "Ask where to save each file" setting.
```

**notifications**
```
Shows a system notification when an export finishes or fails, because large exports can take a minute and the user has usually switched to another tab or window.
```

**contextMenus**
```
Adds two items to the context menu of links to Confluence pages: "Export this page to PDF" and "Export this page + children". They let users export a page without opening it first.
```

**offscreen**
```
Extension service workers cannot create blob: URLs. An offscreen document (reason: BLOBS) turns the generated PDF bytes into a blob URL so chrome.downloads can save the file. It does nothing else and is closed when it is no longer needed.
```

**Host permissions (optional_host_permissions: https://*/*, http://*/*)**
```
No host permissions are granted at install time. Confluence can run on any domain: Atlassian Cloud (*.atlassian.net), Cloud custom domains, and self-hosted Data Center/Server instances on company domains (sometimes plain HTTP inside a company network). The extension can't know these domains in advance, so it declares them as optional and, when the user first exports from a site, calls chrome.permissions.request for that one origin only (e.g. https://wiki.example.com/*). Access is then used only to read content from that Confluence site with HTTP GET requests (same-origin, using the user's existing session) and to open a background tab on that site for printing. While that tab builds the PDF, the browser loads the images and other resources embedded in the pages from wherever they are referenced (usually the same site; authors can also embed images from other hosts), as when the page is viewed; no referrer is sent with them. Users can review and revoke granted sites on the options page or in chrome://extensions.
```

### Remote code

```
No, I am not using remote code.
```
All JavaScript is bundled in the package. The extension pages' CSP is `script-src 'self'; object-src 'self'`.
It uses no `eval`, `new Function` or remotely hosted scripts, styles or fonts.

| Health information | ☐ | |
| Financial and payment information | ☐ | |
| Authentication information | ☐ | The extension never reads cookies, passwords or tokens. Requests rely on the browser's existing session. |
| Personal communications | ☐ | |
| Location | ☐ | |
| Web history | ☐ | Only the current tab's URL is read, on a user action, to identify the page to export. No history is recorded. |
| User activity | ☐ | |
| Website content | ☑ | Confluence page text, images and links are read to build the PDF. Processed locally only. Never transmitted. |
